# 🎨 Tutorial: AI Banner Generator Zaloma Florist

## Apa itu AI Banner Generator?

Tool untuk **generate banner langsung** menggunakan **OpenAI DALL-E 3** dengan brand guidelines Zaloma yang sudah built-in. Semua warna, style, dan aturan visual diterapkan otomatis.

---

## 🚀 Langkah-Langkah Cepat

### 1️⃣ Akses Tool
1. Login ke **Admin Panel Zaloma**
2. Klik tab **"Banner Promo"**
3. Klik tombol **"AI Assistant"** (warna ungu-gradien)

### 2️⃣ Dapatkan OpenAI API Key
1. Buka: **https://platform.openai.com/api-keys**
2. Login dengan akun OpenAI
3. Klik **"Create new secret key"**
4. Copy & paste ke form

> 💰 **Biaya:** ~$0.04 - $0.08 per gambar (DALL-E 3 Standard Quality)
> 
> 📊 **Perkiraan:** 100 banner = ~$5

### 3️⃣ Isi Form Banner
Masukkan detail promo:

```
Headline Utama: GRATIS ONGKIR
Subheadline: ke Malang Kota (opsional)
Deskripsi: Pesan karangan bunga favorit dengan pengiriman 
           gratis ke seluruh area Malang Kota.
Objek Utama: A realistic white flower delivery van with 
            Zaloma branding, standing flower arrangement
Ukuran: Desktop - 1792x1024
```

**Tips Form:**
- ✅ Headline singkat & jelas (maks 100 karakter)
- ✅ Deskripsi detail tapi tidak bertele-tele (maks 300 karakter)
- ✅ Objek utama jelaskan dengan detail (bouquet, standing flower, dll)
- ❌ Jangan menulis tentang warna/style (sudah otomatis sesuai brand)

### 4️⃣ Generate Banner
1. Klik **"Generate Banner"**
2. Tunggu 15-30 detik
3. Banner langsung muncul dengan:
   - ✅ Warna Zaloma (burgundy, cream, gold)
   - ✅ Style premium florist
   - ✅ Typography elegant
   - ✅ Brand identity konsisten

### 5️⃣ Download & Upload
1. Klik **"Download"** untuk save gambar
2. Kembali ke tab **"Banner Promo"**
3. Klik **"+ Tambah Banner"**
4. Upload gambar hasil generate
5. Isi data banner (judul, kota, dll)
6. **Simpan** → banner live di website!

## ❓ FAQ

**Q: Berapa biaya per banner?**  
A: ~$0.04 - $0.08 per gambar (DALL-E 3 Standard). Sekitar $5 untuk 100 banner.

**Q: Apakah perlu top-up?**  
A: Ya, top-up saldo OpenAI di https://platform.openai.com/account/billing

**Q: Berapa lama generate?**  
A: 15-30 detik per banner.

**Q: Ukuran banner apa saja?**  
A: 
- Desktop: 1792x1024 (landscape 16:9)
- Mobile: 1024x1792 (portrait 9:16)
- Square: 1024x1024 (1:1)

**Q: Bisa edit warna atau style?**  
A: Tidak perlu. Warna & style sudah sesuai brand Zaloma otomatis.

**Q: Hasil tidak sesuai?**  
A: Klik "Ulang" untuk regenerate dengan input yang sama. DALL-E 3 punya variasi output.

**Q: Teks di gambar salah eja?**  
A: AI bisa typo pada teks. Solusi:
1. Regenerate beberapa kali
2. Atau download hasil → edit teks manual di Canva/Photoshop
3. Gunakan area kosong untuk teks overlay

**Q: Bisa generate banyak sekaligus?**  
A: Tidak. Harus satu per satu. Tapi cepat (30 detik/banner).

## 💡 Tips Pro

### 1. Deskripsi Objek yang Detail
✅ **Baik:** "A premium pink rose bouquet with white lily accents, elegant burgundy satin ribbon, displayed on a white marble surface"

❌ **Kurang:** "Bouquet bunga"

### 2. Tentukan Mood & Atmosphere
Tambahkan di deskripsi objek:
- "elegant atmosphere"
- "romantic Valentine theme"
- "professional corporate setting"
- "warm family celebration mood"

### 3. Supporting Elements
Sebutkan objek pendukung jika perlu:
- Clock motif (untuk 24 jam)
- Delivery van (untuk gratis ongkir)
- Gift box (untuk promo hadiah)
- Wedding rings (untuk tema wedding)

### 4. Regenerate Beberapa Kali
DALL-E 3 punya variasi. Generate 2-3x dan pilih yang terbaik.

### 5. Save Prompt yang Bagus
Setelah generate, copy prompt di textarea. Save untuk referensi next time.

## 🆘 Troubleshooting

### ❌ "Invalid API key"
- Pastikan copy API key lengkap (biasanya mulai "sk-proj-")
- Generate key baru di OpenAI Platform
- Pastikan API key tidak expired

### ❌ "Insufficient quota"
- Top-up saldo OpenAI
- Cek usage limit di https://platform.openai.com/usage

### ❌ "Content policy violation"
- Hindari kata-kata sensitif
- Jangan request konten yang melanggar policy OpenAI
- Ubah deskripsi jadi lebih netral

### ❌ Warna tidak sesuai
- Seharusnya otomatis burgundy/cream/gold
- Jika tidak, coba regenerate
- Atau screenshot dan report (mungkin bug)

### ❌ Teks salah eja
- Regenerate 2-3x
- Atau download → edit manual di design tool
- AI masih bisa typo pada text rendering

### ❌ Loading terlalu lama
- DALL-E 3 butuh 15-30 detik (normal)
- Jika > 1 menit, refresh page dan coba lagi
- Cek koneksi internet
